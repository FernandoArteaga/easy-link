Sheet for adding, editing or clearing a link's optional title: the URL as context, one TextField marked "(optional)", a clear button, and Save title / Cancel.

- Opened from the More sheet ("Add title" or "Edit title"). Heading follows: "Add title" when empty, "Edit title" when set.
- Trim on save; saving an empty field removes the title and the card falls back to the URL. Suggested limit 80 characters (the card truncates anyway).
- The input is focused when the sheet opens, with the keyboard up; Enter saves.
- Toast after saving: "Title saved" or "Title removed".
