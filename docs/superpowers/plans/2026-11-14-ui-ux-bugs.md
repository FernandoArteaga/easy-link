# UI/UX Bugs (#96 part 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the five bugs listed in issue #96 (plus two small adjacent ones).

**Architecture:** Client-only SvelteKit SPA. Fixes are local to the guard/layout, error mapper, link
helpers, `utils.ts` and `InputField`. No rules or index changes.

**Tech Stack:** SvelteKit 3, Svelte 5 runes, Firebase 13 (Auth, Firestore), Skeleton 5, Tailwind v4.

**Spec:** `docs/superpowers/specs/2026-11-14-ui-ux-bugs-design.md`

## Global Constraints

- No test suite exists. Each task's gate: `pnpm fmt:check && pnpm check && pnpm build` pass, plus the
  manual check listed (emulator: `pnpm firebase-emulator:start` + `pnpm dev`).
- Imports via `#lib/...` with extensions; Prettier style (tabs, no semicolons, single quotes).
- `'all'` must never be written to Firestore.
- Commits on branch `96-improve-ui-and-ux`; no version bump in this slice.

## Review Focus

- Signed-out user hits `/folders` directly → must still end at `/login` (guard must run once ready).
- Sign-in from `/login` → must still forward to `/links`.
- URL without scheme containing uppercase path (`Example.com/AbC?x=Y`) → `example.com/AbC?x=Y`.
- Non-URL text pasted (`Hello World`) → saved unchanged (only lowercase the head when it passes
  `isValidDomain`/`isValidIp`).
- Error toasts for an unmapped Firestore code show the generic message, not `Firebase: ...`.

### Task 1: Wait for auth before guarding

**Files:** Modify `src/lib/stores/user.svelte.ts`, `src/lib/guard.ts`, `src/routes/+layout.svelte`

**Interfaces:** Produces `UserStore.authReady: boolean` (`$state(false)`);
`routeGuard(path: string, isUserAuthenticated: boolean, authReady: boolean): void` returns early when
`!authReady`.

- [ ] Add `authReady`; set `userStore.authReady = true` in the `onAuthStateChanged` callback (both branches, before the `await`).
- [ ] Pass `userStore.authReady` to `routeGuard` in the root layout effect.
- [ ] Root layout: `{#if userStore.authReady}{@render children()}{:else}` centred `LoaderCircle` (`animate-spin`, `aria-label="Loading"`) `{/if}`.
- [ ] Verify gates + manual: signed in, refresh `/folders` → stays on `/folders`; signed out, open `/folders` → `/login`.
- [ ] Commit `fix: wait for auth state before guarding routes`.

### Task 4: Keep URL case

**Files:** Modify `src/lib/utils/utils.ts`, `src/routes/(secured)/+layout.svelte`

**Interfaces:** `normalizeLink(link: string): string`.

- [ ] Implement: if `/^[a-z][a-z\d+.-]*:\/\//i` matches and `new URL` parses → lowercase scheme +
      `host` portion of the original string only (rebuild as `scheme://host` + rest of original after host);
      else if the substring before the first of `/ ? #` passes `isValidDomain` or `isValidIp`, lowercase
      it and keep the remainder; otherwise return the input unchanged.
- [ ] `submitLink` uses `normalizeLink(link)` instead of `toLowerCase()`.
- [ ] Verify gates + manual: `HTTPS://YouTube.com/watch?v=dQw4w9WgXcQ` → `https://youtube.com/watch?v=dQw4w9WgXcQ`.
- [ ] Commit `fix: only lowercase scheme and host of saved links`.
