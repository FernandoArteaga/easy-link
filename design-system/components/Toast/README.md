Inverted pill (`toast-bg` / `toast-ink`) with a small status dot, a short message and an optional action; centered above the dock.

- Success dot `mint-400`; error dot `danger`. One line, sentence case, no title (the old toasts had "Error" + description).
- Placement: bottom center, 16px above the add bar (was bottom-end, hidden under the thumb on phones).
- Deletes always carry **Undo** for ~5 seconds.
