Horizontally scrolling pill chips for picking the folder to view, replacing the underlined tab strip and its visible scrollbar.

- Inactive `surface-2` / `ink`; active `violet-600` / `on-violet`. Optional count in `ink-muted`.
- Scrollbar hidden, scroll-snap to chip starts; the first chip is always "All".
- A dashed "+ New" chip at the end opens the Add folder sheet (replaces the purple + slab). Hide it at the folder limit.
- The organize toggle and Manage folders entry move to the More sheet and the app bar respectively, freeing the row for folders.
- Chips are 36px tall with 8px gaps: the row's hit area is padded to 44px.
